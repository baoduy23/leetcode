# LeetCode: SQL + DSA (Data Engineering track)

Lời giải LeetCode của mình trong quá trình ôn DSA và SQL cho định hướng Data Engineer.
DSA viết bằng **Python 3**, SQL dùng **MySQL** (ghi chú khi khác PostgreSQL).

## Cấu trúc

```
sql/   # chia theo nhóm: basics/join, group by, top-N, window functions, gaps-and-islands, ...
dsa/   # chia theo pattern: arrays-hashing, two-pointers, sliding-window, ..., graph, dp
```

Đặt tên file: `<số bài 4 chữ số>-<slug>.<py|sql>`, ví dụ `dsa/03-sliding-window/0003-longest-substring-without-repeating-characters.py`.
Copy từ `dsa/_template.py` hoặc `sql/_template.sql` để có sẵn header (pattern, Big-O, edge cases).

## Tiến độ

| Phần | Đã giải |
|---|---|
| SQL | 1 |
| DSA | 0 |

## Commit message

`<sql|dsa>: LC <số> <tên bài>`, ví dụ `dsa: LC 1 Two Sum`.
